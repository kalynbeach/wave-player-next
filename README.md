# `wave-player-next`

A local-first audiovisual music player for personal WAV and MP3 libraries.

## Development

```bash
bun install
bun run dev
```

The Bun host binds to `http://localhost:3000` by default. Product scope and implementation acceptance criteria live in [`docs/`](docs/README.md).

## Checks

```bash
bun test
bun run test:coverage
bun run typecheck
bun run check
bun run build
```
